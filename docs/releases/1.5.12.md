# Noto 1.5.12

Formatierungsänderungen lösen keine neue automatische Analyse oder redundante Recherche mehr aus. YouTube-Links können im Serverbetrieb anhand ihrer abrufbaren Untertitel ausgewertet werden.

- Überschriften, Fett/Kursiv, Leerzeilen, weiche Zeilenumbrüche und das Umwandeln einer bestehenden URL in einen benannten Link behalten passende KI-Ergebnisse. Änderungen an Inhalt, Linkzielen, Anhängen, Aufgabenstatus und Code bleiben relevant. Der Vergleich benötigt keinen KI-Aufruf.
- „KI fragen“ und automatische Hintergrundrecherche lesen öffentliche YouTube-Untertitel. Unterschiedliche Links zum selben Video verwenden einen pro Konto gespeicherten Cache für sieben Tage. Deutsch wird bevorzugt, danach Englisch; automatische Untertitel werden gekennzeichnet.
- Videoantworten in „KI fragen“ zeigen wörtliche Belege und Links zur passenden Videosekunde. „In Notiz übernehmen“ erhält diese Belege und Zeitlinks.
- Fehlende Untertitel, gesperrte Videos und Abrufprobleme erscheinen als Hinweise. Geänderte Notizen oder entzogene Freigaben verhindern die Übernahme veralteter Ergebnisse.

Grenzen: höchstens drei Videos pro Auftrag, 16.000 Zeichen mit Zeitmarken pro Video in „KI fragen“ und 5.000 in der Hintergrundrecherche. Längere Transkripte werden als Ausschnitt bzw. Teilergebnis gekennzeichnet. YouTube kann Abrufe vom Hosting-Server blockieren. Der Transkriptabruf benötigt ein Noto-Konto mit Serververbindung und freigegebenem Webzugriff; reine lokale Notizbücher sind nicht abgedeckt.

Geprüft: 426 automatisierte Tests bestanden, ein Test übersprungen; Web- und Server-Build erfolgreich. Ein öffentlicher TED-Vortrag lieferte im lokalen Live-Test 405 deutsche Untertitelabschnitte.

Windows und Linux erhalten signierte Updatepakete. Die Web-App verwendet dieselbe Version.
