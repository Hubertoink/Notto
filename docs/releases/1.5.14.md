# Noto 1.5.14

Hashtag-Änderungen allein lösen keine erneute automatische KI-Analyse oder Recherche aus. Der Notizeditor behält beim Tippen in langen Notizen seine Scrollposition.

- Hinzufügen, Entfernen und Umbenennen von Hashtags im Notiztext erhalten vorhandene KI-Ergebnisse. Überschriften, tatsächliche Textänderungen, Code und Linkziele bleiben für die Analyse relevant. Ausschluss-Tags wie „#privat“ werden weiterhin beachtet.
- Die automatische Textfeldhöhe wird an einer unsichtbaren Kopie gemessen. Das sichtbare Textfeld wird beim Tippen nicht mehr kurz zusammengeschoben, wodurch Chrome die Scrollposition verlieren konnte.
- Reine Höhenänderungen des verfügbaren Bildschirmbereichs lösen keine erneute Textfeldmessung aus. Änderungen der Breite, etwa beim Drehen des Geräts, passen den Textumbruch weiterhin an. Das Übernehmen eines Hashtag-Vorschlags fokussiert das Textfeld ohne zusätzliches Scrollen.

Geprüft: 441 automatisierte Tests bestanden, ein Test übersprungen; Web- und Server-Build erfolgreich. Der Chromium-Layouttest `node scripts/check-editor-scroll.mjs` reproduzierte mit der bisherigen Messung einen Sprung von 2.500 auf 0 Pixel. Mit der Korrektur blieb die Scrollposition bei wiederholten Texteingaben erhalten; Fokus, vollständige Textdarstellung, Verkleinern und Breitenwechsel wurden ebenfalls geprüft.

Der Browsertest verwendet einen mobilen, verkleinerten Viewport. Die tatsächliche Android-Bildschirmtastatur ist darin nicht emuliert; die abschließende Bestätigung auf dem Gerät steht noch aus.
