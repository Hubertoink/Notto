# Noto 1.5.8

KI-Prüfungen können Dokumentanhänge wieder zuverlässig lesen. Web-App und KI-Worker verwenden jetzt denselben dauerhaften Anhangspeicher. Die fehlende Einbindung beim Worker verursachte „ENOENT“-Fehler und ließ betroffene Prüfungen dauerhaft ausstehen.

- Der Worker nimmt beim Start gescheiterte Anhanganalysen wieder auf, sobald alle benötigten Dateien lesbar sind.
- Die Wiederaufnahme berücksichtigt die aktuelle Textversion, ausgeschlossene Notizen und Tags sowie die Einstellungen für automatische KI-Prüfungen. Andere Fehler werden nicht automatisch erneut gestartet.
- Interne Verlinkungen bleiben wie in 1.5.7 ohne Einfluss auf die Gültigkeit einer inhaltlich unveränderten Prüfung.
- PDF-Zitate scheitern nicht mehr an abweichenden Leerzeichen oder Zeilenumbrüchen. Noto speichert die exakt passende Originalpassage; abweichende Wörter oder erfundene Zitate werden weiterhin abgewiesen.

Windows und Linux erhalten signierte Updatepakete. Die Web-App verwendet dieselbe Version.
